# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Smart AI Studio, please report it confidentially:
- Email: `security@smart-ai-studio.local`
- Please do not disclose security issues publicly before a fix is released.
- We will acknowledge receipt within 48 hours and provide a resolution timeline.
